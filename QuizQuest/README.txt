CodeQuest Quiz Website

Updated features:
- 9 topics: HTML, CSS, JavaScript, Java, Python, SQL, DSA, C, C++
- Easy, Medium and Hard levels; 20 questions per quiz
- One-question-at-a-time interface
- Previous, Clear, Skip and Next/Finish controls
- Result statistics and timer
- Optional answer review: Incorrect, Correct and Skipped
- Incorrect review shows the selected answer and correct answer
- Responsive desktop/tablet/mobile layouts
- Footer appears only on Home and Result pages

Open index.html in a browser to start.
